Optional: to embed the Aptos font in PDF exports, copy these two files here
(from a Windows PC with Microsoft 365: C:\Program Files\Microsoft Office\root\vfs\Fonts\private\ or C:\Windows\Fonts):

  Aptos.ttf
  Aptos-Bold.ttf

Word and Excel exports already use Aptos (the font is applied by Office on opening).
Without these files the PDF export falls back to Helvetica.
